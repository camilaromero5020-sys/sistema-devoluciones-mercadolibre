# Sistema Automatizado de Gestión de Devoluciones y Reclamos Postventa - Mercado Libre S.R.L.

#Descripción
El presente proyecto desarrolla un módulo de software automatizado para la gestión integral de devoluciones y reclamos postventa en Mercado Libre, optimizando la trazabilidad de la logística inversa, sincronizando flujos financieros en Mercado Pago y reduciendo la intervención manual en disputas.
