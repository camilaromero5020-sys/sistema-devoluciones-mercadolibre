# Sistema Automatizado de Gestión de Devoluciones y Reclamos Postventa - Mercado Libre S.R.L.

#Descripción
El presente proyecto desarrolla un módulo de software automatizado para la gestión integral de devoluciones y reclamos postventa en Mercado Libre, optimizando la trazabilidad de la logística inversa, sincronizando flujos financieros en Mercado Pago y reduciendo la intervención manual en disputas.

## Indicadores de Control y Estándares de Desempeño

Para la auditoría técnica del sistema, se establecen los siguientes indicadores:

*1. Cobertura de Validación de Entradas:* El 100% de los formularios de carga de datos (como la solicitud de devolución) deben validar campos vacíos o erróneos antes de procesarse.
*2. Tiempos de Respuesta del Servidor:* Las consultas principales del sistema no deben superar los 2 segundos bajo condiciones normales de operación.
*3. Gestión de Errores Críticos:* El tiempo de resolución para errores de bloqueo o fallas críticas reportadas en las incidencias del repositorio debe ser menor a 24 horas.

## Declaración de Uso de IA

Durante el desarrollo de este proyecto se utilizaron asistentes de inteligencia artificial como herramientas de apoyo técnico y metodológico. 

* **Justificación de Prompts:** Los prompts se estructuraron de manera iterativa y directiva, enfocándose en la obtención de plantillas formales para Historias de Usuario bajo el estándar ágil, la estructuración de tableros Kanban y la definición de criterios de auditoría técnica.
* **Correcciones Humanas y Validación:** Las respuestas y sugerencias generadas por la IA fueron revisadas, filtradas y adaptadas críticamente. Se ajustaron los parámetros técnicos al dominio específico del sistema de devoluciones y se validó manualmente que la implementación en el repositorio cumpliera estrictamente con los lineamientos de la cátedra.
